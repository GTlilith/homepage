二、A 模块：银行承兑汇票全流程

票据业务是本岗最长的作业链，共 12 个节点，形成"收票 → 排序 → 配单 → 销号 → 背书 → 打印 → 换票 → 复核 → 制单 → 打印凭证 → 附凭证"的闭环。

A1 打印收款收据

  1. ERP 业务收款查询，日期取前一结算日
  2. 收款单位选本部主体与主体账户，结算方式筛"承兑"
  3. 全部显示后按付款单位排序
  4. 全选 → 打印卡片 → A5 → 单面打印

交付物：当日承兑收款收据。

A2 打印收入汇票

  1. 进入 ERP 应收票据信息，按"小额 / 大额"两档分别筛选
  2. 收票日期取前一日，周末顺延补两日
  3. 到期日期按"收票月份 +5 至 +6"区间筛选，边界精确到收票日
  4. 全选后去除前两行汇总行，打印票据正背面（A4 单面）

不打印清单（便于后续精确配票）：

  • 小额档：面额过小及带零头的票据（如 1 万出头、非整额）
  • 大额档：超过 100 万且属优质银行的票据（不用于日常配单）

A3 整理收入汇票

  • 大额：按金额从小到大
  • 小额：按到款日期从早到晚
排序规则不同，是为了让 A4 配票时"就近取票"——大额配大额申请单，小额配小额申请单。

A4 申请单附汇票（核心判断节点）

第一步：单据合法性校验

  • 抬头主体区分本部 / 异地基地
  • 印章齐全

第二步：欠款金额判断矩阵

场景判断条件是否可付
预付款、发货款单据完备✔ 可直接付
本部 · 一般欠款金额 < 0✘
本部 · 一般剩余额度 ≥ 申请金额✔
本部 · 已开票剩余 + 发票 ≥ 申请金额✔
本部 · 其余结算办理备注中有说明✔
异地欠款金额 < 0✘
异地欠款金额 ≥ 0✔
"欠款金额"为负数表示欠款，为正数表示剩余额度。

第三步：配票策略

  1. 按金额升序排申请单
  2. 10 万以内找小额汇票（每捆按日期堆放，一捆一日）
  3. 10 万以上找大额汇票
  4. 排除流转次数过长（>11 次）及零钞票
  5. 汇票来源单位付好票的，优先回配同等好票（大银行、非偏远地区）
  6. 同金额多张可选时，优先使用流通性偏弱的票据
  7. 回形针夹附；拆分票需当场算出余额并手写标注

A5 备查簿汇票销号

  1. 先筛"被背书人空白"且"主结算行"的记录
  2. CTRL+F 按票据号检索
  3. 本部：已用标黑色（填被背书人 + 手写复核日期），拆分剩余标红色（插入行 + 复制粘贴）
  4. 异地：不标黑色，只标红色并用同样方式记录被背书人与日期
  5. 核对黑色与红色金额之和是否等于原票面额

易错点

  • 同一票号可能存在多张不同金额的票据
  • 涂黄标记的金额 = 已在备查簿中配入申请单的票据，不可重复使用

A6 电子票据背书申请

异地基地

  • 批量收票应答（一手直收）→ 批量背书应答（多次转让）→ 下一步 → 勾选全部 → 提交公司办复核

本部

  • 单张汇票直接搜票号后 9 位
  • 多张汇票按"日期 + 金额"筛选后，按金额排序，核对票号尾号选取

被背书人名册维护（不可省）

  • 按收款单位搜索
  • 校验名称、开户行、账号三者一致，不一致不予办理
  • 新增时选择"被背书人"，新增后需退回等待生效
  • 技巧：先在首张票时一次性检索全部汇票，将新账户提前维护完毕

其他规则

  • 背书金额 = 汇票实际使用金额；单张即为申请金额
  • 出错走"修改删除"重做，不在原单上改

交付物：公司办签字确认的背书申请。

A7 打印拆分汇票

  1. 背书申请 / 复核结果查询
  2. 单据手写当天日期 → 下一步
  3. 同步导出当日付款明细（下载全部），Excel 保留：票号、出票日、到期日、金额（文本转数值）、交易结果
  4. 反选"预处理失败"后对金额求和 —— 用于当日支出明细表与结果复核
  5. 编辑列：前两行仅保留"被背书全称"
  6. 按单位排序，结合金额选票：单张看申请单，多张看拆分汇票，逐笔确认交易结果无失败
  7. 票样连续打印（正面 + 背面），双面打印一份

A8 替换拆分汇票

  • 申请单分为"全整票"与"含拆分票"两类
  • 拆分汇票对折、折角；异地基地一票两份，其中一份不折角留存
  • 换入拆分汇票，同时给原附整票折角标记

A9 结算办理复核确认

  1. 筛选四类承兑 + 主体（本部 / 异地）
  2. 排序选择 → 办理 → 批量办理
  3. 办理后与银行背书结果核对金额一致（依据 A7 导出的付款明细）
  4. 复核后直接确认

A10 凭证制单

申请单整理

  • 按人名分组，再按数量拆分；专项单据单放；代采与新项目单独归类

凭证要素

字段规则
日期申请单公司办签字日
财务编号本部按凭证列表手动续编；异地自动生成
摘要"银承转让 + 对方单位（异地需后缀标识）"
借方金额同单位总额不变，先清空再自动回填剩余金额
票据科目应收票据贷方，按部门归属
现金流量按用途映射（日常支出 / 质保金及投资 / 代采 / 主体间调拨 / 异地）

三类特殊场景

  • 代扣气款：申请单需标注代扣金额；借方记申请单总额，加一行挂气体购销科目贷方
  • 代扣电费：按 ÷1.13 价税分离，一行记电费收入（数量单价自动带出），一行记增值税额
  • 电汇打款：借方为申请汇款额；加一行按"打款额 × 贴现利率 ÷ 2"计提利息并计入待摊；再加一行银行存款记实付额；末行应收票据记承兑实付额

A11 打印凭证

  • ERP 凭证制单列表 → 主体 → 月份 → 凭证类型"票据" → 筛选
  • 选中起始票打印 → 拉至末尾修改终止票号 → 直接打印
  • 纸张 A5、横向、单面

A12 申请单附凭证

  • 凭证按票号从小到大
  • 一张凭证后按序附对应（可能多张）申请单

三、B 模块：电汇与资金台账

B1 台账日清（每日首要动作）

  1. 逐行下载昨日收支 Excel 并打印回单；有托收、付款的账户全部核查
  2. 更新"昨日表"：
    • 余额 → 银行昨日余额
    • 付款 → 各行付款合计
    • 收款 → 拆分为货款 / 水电费 / 往来（退款、煤款、社保返还、子公司款项等）
  3. 更新"做凭证"表与"开票室"表
  4. 三方交叉核对：ERP 收款单（到账日期昨日 + 结算方式电汇 + 合计扣除往来款）＝ 开票室收款合计
  5. 查收款登记：只看昨日；水电费由出纳认领，其余归开票室；发现未登记则截图通知业务员加户
  6. 打印：昨日表两份（领导 / 自留）、做凭证一份（自留）、开票室一份（排序后签字）

B2 台账特殊处理

  • 固定账户按月维护：公寓楼电费、园区综合办（收款 / 充值 / 办卡 / 考核）、园区装车费
  • 每日零散入账不逐笔更新余额；有大额进出时按月初余额记账，月末汇总为一笔收款凭证
  • 月末核对：部门专项（如电瓶车电费月末提现）、外币账户

B3 销售收款入账与收款凭证

  1. 排除项：煤款、托收、货损等往来款不计入开票室货款
  2. 查发银行收票记录，按时间排序确认是否已发，避免重复
  3. 业务中台 → 合同收款单 → 销售收款；筛选结算方式 + 昨日日期 + 收款账号
  4. 每张凭证总额须与昨日收款表对应银行收款额一致
  5. 填写部门归属（按银行账户对应销售条线）
  6. 外币：先录外币金额再改币种；到账额、手续费（插入分录）、原始汇入额三行分离；同一公司多条凭证分开生成

B4 银行转账制单

  1. 先核对申请单可付性（欠款为负不可付）
  2. 限额分笔：超过单笔限额（如 300 万、500 万）必须拆笔，否则超额无法落地
  3. 他行按 4 位尾号检索
  4. 新户维护：ERP 结算处复制户名与行号 → 制单页模糊查开户行全称 → 取行号回制单页 → 保存为常用收款账户
  5. 制单完成后在申请单上回写付款银行尾号

B5 付款结算

  • 部分付款：单选 → 办理 → 填付款账号并修改实际付款金额 → 保存提交
  • 已有付款账号的单据按实际付款账号修正
  • 扣除利息的付款按实付金额结算
  • 流程：办理 ✔ → 复核 ✔

四、C、D、E 模块

C 银行回单与流水

  • 批量回单下载：账户查询 → 电子回单查询 → 查询类型批量 → 起止日期月初至月末 → 打印状态"未打印" → 交易方向"贷" → PDF 合并下载
  • 收入下载：票据业务 → 电商汇票 → 查询

D 贴现业务

  • 按票据金额与到期日筛选拟贴现票据
  • 利率区分电费票与市场报价，按当期报价取值
  • 贴给非开票行需另做背书申请
  • 各行网银操作路径不同（商业汇票背书签收、在线秒贴、出票经办、银承申请书维护），需分别建立操作卡片
  • 保证金与利息结构：收方含保证金、利息及结构性存款收益；付方含贴现利息与手续费

E 凭证附回单规范

凭证类型附件构成
收款凭证 + 贷方回单（外币另加汇款通知书）
付款（一般）凭证 + 签字申请单 + 借方回单（申请单只需一次签字）
付款（报销）凭证 + 报销单 + 借方回单（报销单无需二次签字）

收款凭证排序技巧：ERP 凭证联查预览 → 定位应收账款行 → 辅助导入导出 → Excel 仅保留往来单位列 → 分列去数字只留名称，避免跨日期凭证乱序。

五、F 模块：跨部门流转

F1 申请单领取与送审

  1. 一楼公司办按文件盒（本部 / 异地）依人名查找，分日期签字
  2. 核对单位、金额、方式（承兑 / 电汇），两者分开放置
  3. 铅笔先写草稿，减少涂改：合计金额、其中承兑、其中电汇
  4. 拍照报送：按项目组归类 → 今日合计 → 承兑小计 → 电汇小计
  5. 上午送领导审批，下午跟进结果；获批后向公司办领取对应银行复核盘

F2 退款可付性判断

  1. 科目余额表按月查询（跨度一年）→ 应收账款 → 无级次
  2. 右键新窗口打开单位余额表 → 输入往来单位 → 单位三栏账
  3. 有往来（收入）记录：看凭证编号
    • 有电汇记录且金额大于退款申请额 → 可走电汇
    • 仅有承兑票据，或电汇金额小于退款申请额 → 不走电汇
  4. 无往来记录：回到第一步扩大查询跨度

F3 退宿退款（多部门串联示例）

行李核查（人力资源确认时限）→ 开票室缴费 → 物业单据 → 押金收据缺失时从科目余额表调取辅助三栏账并复印凭证 → 开具两张领款单（金额大小写、领款人签字）→ 财务负责人签字 → 人力资源签字 → 公司办签字盖章 → 开票室取款。

六、可复用的作业原则

从上述流程中提炼的六条通用规则，也是本手册的方法论内核：

  1. 三方一致原则 — 申请单、票据、凭证三处金额必须互相对得上；银行流水与台账、开票室总额每日交叉核对一次。
  2. 编号唯一可追溯 — 票号取后 9 位、凭证号连续编排、付款银行尾号回写单据，任一凭据都能反查到源头。
  3. 分色标记法 — 黑色=已全额使用，红色=拆分剩余，黄色=已配入申请单；颜色替代记忆，避免重复占用。
  4. 日清月结 — 每日固定完成流水更新与三方核对；零散入账不逐笔动余额，月末一次性合并。
  5. 前置校验优于事后纠错 — 可付性判断、限额分笔、名称/行号/账号三一致校验，都放在动作发生之前。
  6. 异常清单化 — 不打印清单、不接收清单、易错点清单固化在流程里，把个人经验转成可交接的规则。
