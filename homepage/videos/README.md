# Homepage Demo Videos

主页实际使用以下 4 个 MP4 文件（文件名区分大小写）：

- `PDFtool.mp4`：票据 PDF 处理工具
- `autoclick.mp4`：AutoClick 自动点击扩展
- `keyboardsound.mp4`：键盘数字发音软件
- `KFagent.mp4`：空分开车智能领航员

页面使用 `preload="metadata"`，首次打开只加载视频元数据，不会自动播放或一次性下载全部视频。

## 当前文件大小

- `PDFtool.mp4`：约 17.4 MB
- `autoclick.mp4`：约 18.3 MB
- `keyboardsound.mp4`：约 6.0 MB
- `KFagent.mp4`：约 20.8 MB

前三个较大的视频后续可压缩到 8–12 MB，以改善移动网络加载速度；当前版本可以先部署验证。

## 建议导出规格

- 格式：MP4（H.264 视频 + AAC 音频）
- 分辨率：1280×720
- 帧率：25 或 30 fps
- 单个文件：建议小于 12 MB
- 视频封面（可选）：`PDFtool-cover.jpg`、`autoclick-cover.jpg`、`keyboardsound-cover.jpg`、`KFagent-cover.jpg`
